# ONE-PAGE QUICK START

## 🎯 DO THIS IN ORDER (Next 2 hours)

### STEP 1: Check Hardware (5 min)
```
✅ ESP8266 has blue LED (powered on)
✅ DHT11 connected to breadboard
✅ Water sensor connected to breadboard
✅ All jumper wires fully inserted (not loose)
✅ No visible wire bridges/shorts
```

### STEP 2: Download Arduino IDE (10 min)
```
1. Visit: https://www.arduino.cc/en/software
2. Download and install
3. Open Arduino IDE
```

### STEP 3: Add ESP8266 Support (15 min)
```
In Arduino IDE:
1. File → Preferences
2. Paste in "Additional Boards Manager URLs":
   http://arduino.esp8266.com/stable/package_esp8266com_index.json
3. Tools → Board → Boards Manager
4. Search "esp8266" → Install
5. Wait for completion
```

### STEP 4: Install Libraries (10 min)
```
In Arduino IDE:
1. Sketch → Include Library → Manage Libraries
2. Search "DHT" → Install "DHT sensor library" by Adafruit
3. Search "Adafruit Unified" → Install by Adafruit
4. Close when done
```

### STEP 5: Configure WiFi (5 min)
```
Open: sensor_code.ino

Find lines 10-11:
  const char* ssid = "YOUR_WIFI_SSID";
  const char* password = "YOUR_WIFI_PASSWORD";

Replace with YOUR WiFi:
  const char* ssid = "MyWiFi";
  const char* password = "MyPassword123";
```

### STEP 6: Upload Code (10 min)
```
1. Connect ESP8266 to computer via USB
2. Tools → Board → NodeMCU 1.0 (ESP8266)
3. Tools → Port → Select your COM port
4. Click Upload (→ button)
5. Wait for "Wrote XXXXX bytes" message
```

### STEP 7: Get IP Address (2 min)
```
Tools → Serial Monitor (Ctrl+Shift+M)
Set baud to 115200

Look for:
[WIFI] IP Address: 192.168.X.XXX

Write it down: _____________________
```

### STEP 8: Update Dashboard IP (2 min)
```
1. Open nepal_ews_dashboard.html in browser
2. Scroll down → IP Configuration panel
3. Replace 192.168.1.100 with YOUR IP
4. Click "UPDATE IP"
5. Check: Dashboard shows "● ONLINE"
```

## 🔌 PIN CONNECTIONS

```
DHT11:
  VCC → 3V3
  DATA → D4
  GND → GND

WATER SENSOR:
  VCC → 3V3
  GND → GND
  SIG → A0
```

## 🚨 IF SOMETHING GOES WRONG

| Problem | Solution |
|---------|----------|
| No power | Check USB cable, restart |
| No WiFi | Check WiFi name/password, move closer to router |
| Dashboard OFFLINE | Check IP address, reload page |
| No sensor data | Check jumper wires, restart ESP8266 |
| Compiler error | Install DHT libraries, check board selection |
