💡 Assembly Tips:

  • Power Rails: Connect 3.3V rail continuously from top to bottom
  • Ground Rails: Connect GND rail continuously from top to bottom
  • DHT11 Placement: Place on breadboard with legs spread across columns
  • Pull-up Resistor: Connect from DHT DATA pin to 3.3V rail (stabilizes signal)
  • Water Sensor: Keep away from DHT11 to avoid interference
  • Jumper Wires: Use appropriate lengths (too long = signal noise)
  • Double Check: Verify no wires cross power/ground rails unintentionally

Troubleshooting Circuit Check

🔧 Diagnostic Checklist:

  • ✅ Blue LED on ESP8266: Confirms USB power delivery
  • ✅ Serial Monitor Connection: Verifies data communication
  • ✅ Water Sensor 0-1023 Range: Confirms ADC working
  • ✅ DHT Temperature Reading: Confirms digital GPIO functioning
  • ✅ WiFi IP Address: Confirms network stack operational
  • ✅ JSON Output at /data: Confirms API endpoint responding
  • ❌ Stuck at 0 or 1023: Check A0 connection or sensor power
  • ❌ DHT Read Failed: Check D4 connection or add pull-up resistor
  • ❌ No IP Address: Check WiFi SSID/password, router 2.4GHz
