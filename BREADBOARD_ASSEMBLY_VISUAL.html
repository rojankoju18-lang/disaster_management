📐 STEP 1: Complete Assembly Overview

✨ What You'll Connect:

  1. RED WIRES (3.3V) - Connect power to all sensor VCC pins
  2. BLACK WIRES (GND) - Connect ground to all sensor GND pins
  3. YELLOW WIRE (D4) - Connect DHT11 DATA pin to ESP8266 D4
  4. GREEN WIRE (A0) - Connect Water sensor SIGNAL to ESP8266 A0
  5. 10kΩ RESISTOR - Add pull-up between DHT DATA and 3.3V
  6. USB CABLE - Power the entire system

📍 STEP 2: Detailed Breadboard Placement

📝 Component Placement Instructions:

  1. Place DHT11 sensor at columns 1-3, row A
  2. Place Water sensor at columns 5-7, row A
  3. Insert 10kΩ resistor between DHT DATA and Power Rail
  4. Connect red wires from Power Rail to all VCC pins
  5. Connect black wires from Ground Rail to all GND pins
  6. Connect yellow wire from DHT DATA to ESP8266 D4
  7. Connect green wire from Water SIGNAL to ESP8266 A0

❌ DON'T DO THIS:

✗ Connect USB while wiring (short circuit risk)
✗ Force components into breadboard
✗ Use 5V power for sensors (must be 3.3V)
✗ Mix up red and black wires
✗ Leave loose wires touching each other
✗ Ignore the 10kΩ pull-up resistor
✗ Connect wrong pins to ESP8266
✗ Bend sensor pins excessively

🔍 Quality Checks:

  • Visual Inspection: No visible wire damage or insulation peeling
  • Connection Firmness: All wires fully inserted, not loose
  • Component Orientation: DHT11 4-pins spread across breadboard rows
  • Resistor Placement: 10kΩ between DATA pin and 3.3V rail
  • Color Coding: Each wire matches its connection type
  • No Bridges: No accidental wire shorts across power/ground
  • Take Photos: Photograph your completed circuit from multiple angles

🔧 STEP 6: Common Wiring Issues & Fixes

⚠️ Issue: DHT11 Not Reading

Cause: Weak signal on DATA pin
Solution:
1. Verify 10kΩ resistor is properly installed between DATA and 3.3V
2. Check yellow wire is firmly inserted into D4 pin
3. Ensure DHT11 VCC is connected to 3.3V (NOT 5V)
4. Try using a shorter yellow wire (less noise)
5. Restart ESP8266 after fixing

⚠️ Issue: Water Sensor Reading 0 or 1023

Cause: A0 pin not connected or sensor not powered
Solution:
1. Check green wire is fully inserted into A0 hole
2. Verify red wire to sensor VCC is connected
3. Check black wire to sensor GND is connected
4. Try different jumper wire for green signal
5. Test with multimeter if available

⚠️ Issue: No Power (ESP8266 Blue LED Not On)

Cause: USB cable not properly connected
Solution:
1. Reconnect USB cable firmly
2. Try different USB port on computer
3. Try different USB cable (test with phone if available)
4. Check for loose USB connector
5. Ensure no wires are shorting power/ground on breadboard
