🔌 Sensor Connection Details

1️⃣ DHT11 Temperature & Humidity Sensor

Pin Configuration:
  • Pin 1 (VCC) → 3.3V Power Rail
  • Pin 2 (DATA) → ESP8266 D4 (GPIO2) with 10kΩ pull-up resistor to 3.3V
  • Pin 3 (GND) → Ground Rail
  • Pin 4 (NC) → Not Connected

2️⃣ Water Level Sensor (Analog)

Pin Configuration:
  • VCC (Red wire) → 3.3V Power Rail
  • GND (Black wire) → Ground Rail
  • SIGNAL (Green/Yellow wire) → ESP8266 A0 (Analog Input)

Reading: 0-1023 ADC value = 0-8 meters water height

3️⃣ LM393 Soil Moisture Sensor Module

4-Pin Module Configuration:
  • VCC (Pin 1) → 3.3V Power Rail
  • GND (Pin 2) → Ground Rail
  • DO (Pin 3) → ESP8266 D0 (GPIO16) - Digital Output (Threshold)
  • AO (Pin 4) → ESP8266 D1 (GPIO5) - Analog Output (Proportional)
⚙️ Potentiometer Calibration:
  1. Insert soil probe into COMPLETELY DRY soil
  2. Slowly rotate the potentiometer until DO switches to HIGH (LED off if equipped)
  3. Insert probe into WET SOIL or WATER
  4. Verify DO switches to LOW (LED on if equipped)
  5. Fine-tune for your desired sensitivity threshold
  6. Typical threshold: 40-60% soil moisture
✅ Output Behavior:
  • DO (Digital): HIGH (1) = Dry soil | LOW (0) = Wet soil
  • AO (Analog): 0V (dry) to 3.3V (wet) proportional output

📋 ESP8266 Pin Mapping Summary

ESP8266 Pin GPIO Number Pin Type Connected To Function
A0 ADC Analog Input Water Level Sensor SIGNAL Water depth measurement (0-1023)
D0 GPIO16 Digital Input LM393 DO (Digital Output) Soil moisture threshold detection
D1 GPIO5 Digital Input* LM393 AO (Analog Output) Soil moisture proportional level
D4 GPIO2 Digital Input DHT11 DATA Temperature & humidity sensor
3V3 — Power Output All sensors VCC 3.3V power supply
GND — Ground All sensors GND Common ground reference

*D1 reads digital levels but can simulate analog through rapid sampling or voltage divider

🔧 Troubleshooting Checklist

Symptom Likely Cause Solution
DHT11 reads "NaN" No pull-up resistor or loose connection Add 10kΩ pull-up resistor to 3.3V on DATA pin
Water sensor reading always 0 Pin A0 not connected or sensor unpowered Check A0 connection and sensor VCC/GND
LM393 DO not switching Potentiometer needs calibration or sensor dry Calibrate potentiometer with wet/dry soil
All sensors reading zero Ground rail not properly connected Verify all GND connections are on BLACK RAIL
ESP8266 not responding USB cable issue or insufficient power Use quality USB cable, 500mA+ power supply

✅ System Verification Checklist

Physical Connections:

  • ☐ ESP8266 blue LED is ON
  • ☐ All sensor VCC pins connected to RED RAIL
  • ☐ All sensor GND pins connected to BLACK RAIL
  • ☐ DHT11 DATA pin connected via 10kΩ pull-up
  • ☐ Water sensor SIGNAL connected to A0
  • ☐ LM393 DO connected to D0
  • ☐ LM393 AO connected to D1
  • ☐ No loose or bridged jumper wires

Sensor Operation:

  • ☐ DHT11 reports temperature ~25°C
  • ☐ Water sensor reads < 1000 (dry state)
  • ☐ LM393 DO changes state when moisture changes
  • ☐ Serial Monitor shows all values updating
  • ☐ Dashboard displays "ONLINE" status
  • ☐ Gauges animate with sensor data
  • ☐ Alerts trigger at thresholds
